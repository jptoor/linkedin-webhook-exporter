Sample pages

Static pages that mimic each LinkedIn surface the extension supports, including the 2026 layout with hashed class names. Load dist-test/ as an unpacked extension (built with npm run build:test), point the webhook at http://127.0.0.1:8787/hook from LWE_ALLOW_UNSIGNED=1 npm run receiver, and click around. The same files are the unit and acceptance fixtures.

  • Profile, classic layout
  • Profile, 2026 layout (SDUI) with emoji, credentials, grouped roles
  • People search, 2026 layout (chatter lines, pronouns, mononyms)
  • Sales Navigator search, 3 pages × 25 (messy names)
  • Sales Navigator search with delayed lazy rows
  • Sales Navigator search whose second half of rows is appended after scrolling (Next enabled only then)
  • Sales Navigator lead list (no Next button, 12 rows)
  • Sales Navigator lead page (grouped experience, nested heading spans)
